# CMD Calculator

A simple command-line calculator built with Python.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Negative numbers
- Decimal numbers
- Parentheses
- Modulus (%)
- Power (**)
- Exit command

##Technology
Python
Command Prompt
Git & GitHub


## How to Run

```bash
python calculator.py

##Example
Enter calculation: -10 + 5
Result: -5

Enter calculation: (-5) * 3
