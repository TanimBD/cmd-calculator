# CMD Calculator

A simple command-line calculator built with Dart.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Negative numbers
- Decimal numbers
- Input validation
- Division by zero handling
- Exit command

## Technology

- Dart
- Command Prompt
- Git & GitHub

## How to Run

Make sure Dart SDK is installed, then run:

```bash
dart run calculator.dart
